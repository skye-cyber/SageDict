# Desktop Dictionary

A modern, lightweight cross-platform dictionary application.

## Features

- **Fast JSON-based search** with debouncing and fuzzy matching
- **Vim-inspired dark theme** with rich dark grays and blues
- **Toggleable dark/light mode** with smooth transitions
- **Global shortcut**: `Cmd/Ctrl + Shift + D` to show/hide
- **Context isolation** for security
- **Small bundle size** (~50MB)
- **Modern UI** with React Icons and Framer Motion animations
- **AI integration points** ready for future enhancements

```bash

# Generate sample JSON data
python3 scripts/json_init.py

# Run in development
npm run dev

# Build for production
npm run build
```

## Data Storage

The app now uses **JSON storage** instead of SQLite:

1. Sample data is generated by `scripts/json_init.py`
2. Data is stored at `assets/dictionary.json`
3. On first launch, the JSON file is copied to the user's data directory
4. The JSON structure follows this format:

```json
{
  "word": "example",
  "phonetic": "/ɪɡˈzɑːmpəl/",
  "part_of_speech": "noun",
  "definition": "A thing characteristic of its kind or illustrating a general rule.",
  "example": "The place is an example of multicultural Britain at its best."
}
```

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + Shift + D` | Show/hide app |
| `Cmd/Ctrl + K` | Focus search |
| `Escape` | Clear search |

## Technical Stack

- **Frontend**: React 18 + TypeScript + Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons (Feather icons)
- **Storage**: JSON-based data
- **Build**: Electron + Vite
- **Styling**: Tailwind CSS with custom Vim-dark theme

## Theme Customization

The app features a **Vim-inspired dark theme** that you can customize in `tailwind.config.js`:

```js
// Vim-inspired dark theme colors
vimdark: {
    50: '#2d2d2d',    // Lightest dark
    100: '#262626',
    200: '#1e1e1e',
    300: '#1a1a1a',
    400: '#151515',
    500: '#121212',    // Default dark background
    600: '#0f0f0f',
    700: '#0a0a0a',
    800: '#050505',
    900: '#000000'     // Darkest
}
```
